# Comptes de consulta

App web per portar la comptabilitat d'una consulta de psicologia: visites del centre i privades, resum mensual, factures als pacients i registre de les factures del centre.

- Funciona sense connexió i es pot instal·lar a l'iPad (Safari → Compartir → Afegeix a la pantalla d'inici).
- **Les dades no surten mai del dispositiu.** Es guarden al navegador. Aquest repositori només conté el codi.
- Fes còpies de seguretat des de Configuració.
